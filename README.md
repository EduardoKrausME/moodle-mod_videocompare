# Video Compare (mod_videocompare)

Video Compare is a Moodle activity for comparing two or more videos in the same learning activity.

Teachers can add uploaded videos, direct video URLs, YouTube videos, and Vimeo videos; create required comparison
questions; and optionally anchor questions to moments in two videos. Students can watch videos side by side when space
permits, switch quickly between videos, create timestamp-to-timestamp comparisons, answer required comparison questions,
and resume from their latest position.

The activity tracks viewing progress separately for every video using merged watched intervals and calculates an overall
activity percentage. Reports show per-video progress, overall progress, required-question completion, answers, and
timestamp comparisons.

Designed from the interaction and tracking concepts used in:
https://github.com/EduardoKrausME/moodle-mod_videoprogress

## Installation

Install the folder as:

`mod/videocompare`

Then complete the Moodle upgrade process.
